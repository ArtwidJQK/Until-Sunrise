# Until Sunrise

Interactive Cinematic Memory Experience — Web prototype and production documentation repository.

## Quick Start

Open `app/index.html` in a browser. No build step is required for this prototype.

## Repository Structure

- `docs/aios/`: AI Operating System Specification (AIOS 1.0)
  - `AIOS.md`: Combined master specification document
  - `01_Constitution.md`: Mission, values, and golden rules
  - `02_Repository_OS.md`: Memory layers, mandatory files, and persistence rules
  - `03_Execution_Engine.md`: Autonomous execution lifecycle and checkpoints
  - `04_Repository_Intelligence.md`: Health metrics, debt register, and risk matrix
  - `05_Reflection.md`: Learning, root cause analysis, and anti-patterns
  - `06_Governance.md`: Authority hierarchy, roles, and decision classes
  - `07_Policy_Engine.md`: Executable policies and enforcement levels
  - `08_Multi_Agent.md`: Multi-agent collaboration and handover protocols
  - `09_Recovery.md`: Recovery protocols after token/context exhaustion
  - `10_Output_Contract.md`: Structured output standards and completion criteria
  - `APPENDICES.md`: Glossary, mandatory file schemas, and naming standards
- `docs/00_Foundation/`: Confirmed project foundation
- `docs/01_Studio/`: Production status and studio tracking
- `app/`: Web prototype entry point (`index.html`, `main.js`, `styles.css`)
- `assets/`: Asset placeholders and media
- `content/`: Narrative and scene data placeholders
- `systems/`: Reusable runtime systems

## Current Scope

- Opening login experience.
- Gentle memory-oriented visual language.
- Placeholder entry transition.
- No story events, dialogue, inventory, combat, quests, or puzzle logic yet.

## Source of Truth

Production documentation lives under `docs/`. Underspecified material remains marked as `Pending`.
