# Anti-Patterns

## AP-0001: Implementing story content from external source material before authority mapping

| Field | Value |
| --- | --- |
| Why it occurs | Detailed source documents can look complete enough to turn directly into scenes or dialogue. |
| Consequences | Unsupported canon promotion, emotional misrepresentation, contradictory documentation, and expensive rework. |
| Detection | A scene, character claim, timeline entry, or dialogue line lacks an approved repository source and decision reference. |
| Avoidance | Complete source intake, record authority and approval state, then create knowledge documents in dependency order. |
| Related risks | KNO-0001, OQ-0001 |
