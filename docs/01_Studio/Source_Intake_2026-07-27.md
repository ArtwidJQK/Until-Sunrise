## Non-Canonical Extraction Summary

The source material supports the following production hypotheses. They are intentionally summarized at a high level to avoid duplicating sensitive narrative detail before approval.

- Until Sunrise is framed as an interactive cinematic memory experience centered on emotional truth, healing, growth, and ordinary acts of care.
- The source proposes an opening that feels like entering a lived-in room rather than a conventional menu, with interface elements integrated into the space.
- The source proposes a guided memory journey, simple observational interactions, and occasional reflective choices that affect perspective rather than historical events.
- The source proposes that relationship events follow a real chronology and that creative adaptation must not alter the nature or order of approved events.
- The source contains detailed claims about the relationship history, both protagonists' vulnerabilities, and the need to show conflict without assigning a permanent villain.
- The source treats visual motion, atmosphere, camera, sound, objects, and silence as storytelling tools rather than decorative features.
- The supplemental document reinforces that both characters must be portrayed with empathy and that conflict should be represented from both perspectives.

These statements are source-derived hypotheses. They are not repository canon and cannot yet be used to write scene events, dialogue, character conclusions, or final visual requirements.

## Intake Findings

### Source Classification

SRC-001 combines several document types that should eventually have separate repository owners. It contains reference material, proposals, asserted personal-history claims, and implementation direction in one file. This makes it useful source evidence but unsuitable as a single authoritative production document.

SRC-002 is a focused supplement to relationship and character material. It adds detail but does not carry a recorded approval status. It should be reviewed alongside, rather than independently from, the relationship chronology.

### Sensitive-Content Handling

Relationship and supporting-character claims concern real people. Future documents must preserve emotional truth, avoid blame, distinguish documented facts from interpretation, and never use a person's death, conflict, or vulnerability as spectacle. No scene or dialogue should be produced from these sources before approval.

### Current Prototype Gap

SRC-001 proposes an opening-space concept, while the current prototype is only a generic opening form with CSS placeholders. This is not treated as an implementation failure or a change request. A scene specification and asset policy are dependencies before the prototype can responsibly move toward that proposal.
