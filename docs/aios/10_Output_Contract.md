# ======================================================================
# Until Sunrise Studio
# AI Operating System Specification (AIOS)
# Part 10: Output Contract
# Version 1.0
# Status: Mandatory
# Applies To: Every AI response that performs production work.
# Authority: Founder
# ======================================================================

# 150. PURPOSE

Every execution SHALL produce
structured, predictable outputs.

Outputs shall improve repository quality.

---

# 151. OUTPUT PRINCIPLES

Outputs SHALL be

Correct

Complete

Traceable

Actionable

Maintainable

Repository-oriented

---

# 152. REQUIRED OUTPUT ELEMENTS

When applicable,
every production response SHALL include

Objective

Completed work

Files affected

Decisions made

Dependencies reviewed

Risks identified

Recommended next task

---

# 153. IMPLEMENTATION OUTPUT

Implementation responses SHALL describe

What was implemented

Why

Affected components

Verification performed

Documentation updated

Remaining work

---

# 154. DOCUMENTATION OUTPUT

Documentation responses SHALL identify

Documents updated

Reason

Affected areas

Related decisions

---

# 155. REVIEW OUTPUT

Review responses SHALL classify findings

Passed

Warning

Issue

Critical

Every issue SHALL include
a recommendation.

---

# 156. PROPOSAL OUTPUT

Proposal responses SHALL contain

Purpose

Current state

Proposed change

Benefits

Risks

Affected artifacts

Approval requirement

---

# 157. ERROR REPORTING

Errors SHALL include

Description

Cause

Impact

Recommended resolution

Severity

Unknown causes
shall be explicitly marked unknown.

---

# 158. COMPLETION CRITERIA

A task is complete only if

Implementation finished

Verification completed

Documentation updated

Repository synchronized

Handover prepared

Relevant project state updated

Otherwise,

the task remains in progress.

---

# 159. QUALITY STANDARD

Outputs SHALL prioritize

Accuracy

Consistency

Traceability

Long-term maintainability

Output length
is never a quality metric.

---

# 160. FINAL PRINCIPLE

Every execution shall leave the project

more understandable,

more maintainable,

more recoverable,

and more valuable

than before execution began.

This principle overrides
all optimization decisions.
