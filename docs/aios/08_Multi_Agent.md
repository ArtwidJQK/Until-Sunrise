# ======================================================================
# Until Sunrise Studio
# AI Operating System Specification (AIOS)
# Part 8: Multi-Agent Collaboration Protocol
# Version 1.0
# Status: Mandatory
# Applies To: Every AI agent participating in production.
# Authority: Founder
# ======================================================================

# 125. PURPOSE

The repository shall support seamless collaboration
between multiple AI agents.

No task shall depend on a specific model.

Every qualified AI agent shall be capable of
continuing production using repository artifacts alone.

---

# 126. AGENT INDEPENDENCE

Every AI agent is replaceable.

No agent may create knowledge
that exists only within its own context.

Repository knowledge always has priority
over conversational memory.

---

# 127. SHARED RESPONSIBILITY

All agents share responsibility for

Repository integrity

Knowledge preservation

Documentation quality

Decision traceability

Production continuity

Ownership of implementation
does not imply ownership of project knowledge.

---

# 128. AGENT HANDOVER

Every execution session SHALL end
with a complete handover.

The handover shall include

Current objective

Completed work

Remaining work

Known issues

Open questions

Risks

Recommended next action

Repository status

No session shall terminate
without preparing the next session.

---

# 129. WORK OWNERSHIP

Each active task SHALL have
exactly one responsible agent.

Supporting agents MAY contribute

Reviews

Documentation

Testing

Research

Verification

Task ownership shall remain unambiguous.

---

# 130. PARALLEL EXECUTION

Independent tasks MAY execute in parallel.

Examples

Documentation

Testing

Asset organization

Implementation

Architecture review

Parallel work shall never modify
the same authoritative artifact
without synchronization.

---

# 131. SYNCHRONIZATION

Before completing a task,
an agent SHALL synchronize

Repository state

Related documentation

Decision records

Project status

Dependency status

Synchronization precedes handover.

---

# 132. CONFLICT DETECTION

Conflicts include

Contradictory documentation

Conflicting implementation

Duplicate authority

Canon inconsistency

Dependency mismatch

Detected conflicts SHALL be documented
before resolution.

---

# 133. CONFLICT RESOLUTION

Resolve conflicts by

Identify affected artifacts

↓

Determine authority

↓

Review evidence

↓

Select authoritative source

↓

Update repository

↓

Record decision

Conflicts shall never be resolved silently.

---

# 134. TASK TRANSFER

When transferring work,

the outgoing agent SHALL provide

Task objective

Current progress

Files affected

Known risks

Blocking issues

Recommended continuation

The incoming agent SHALL review
repository state before continuing.

---

# 135. REVIEW RESPONSIBILITY

Any agent MAY review another agent's work.

Review SHALL evaluate

Correctness

Completeness

Consistency

Documentation

Compliance

Reviews SHALL record findings.

---

# 136. DUPLICATE WORK PREVENTION

Before starting implementation,

the agent SHALL verify

Existing implementation

Existing documentation

Existing proposals

Existing decisions

Duplicate work is production waste.

---

# 137. COMMUNICATION STANDARD

Repository communication SHALL be

Objective

Concise

Traceable

Actionable

Evidence-based

Conversation-specific assumptions
shall not appear in repository artifacts.

---

# 138. SESSION TERMINATION

Before ending a session,
the agent SHALL confirm

Current task status recorded

Documentation updated

Repository synchronized

Handover completed

Outstanding issues documented

Checkpoint generated

Session termination without handover
is considered incomplete execution.

---

# 139. DEFINITION OF SUCCESS

Multi-agent collaboration succeeds when

Any qualified AI agent

can continue production

without additional explanation,

using repository artifacts only.
